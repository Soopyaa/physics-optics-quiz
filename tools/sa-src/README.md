# 简答真题的转录源

这里的 `<年>.json` 是「真题简答题」板块的原始转录，`tools/sa-build.py` 把它们
拼成上层的 `sa-data.js`。要改题目或答案，改这里的 JSON，然后：

```sh
python3 tools/sa-build.py     # 校验 + 重新生成 sa-data.js
python3 tools/sa-build.py --check   # 只校验
```

改完记得把 `sw.js` 里的 `CACHE` 版本号 +1。

## 源文件

- 题目卷：`~/Desktop/物理光学/840真题.pdf`（90 页扫描件，无文字层）
- 答案册：`~/Desktop/物理光学/电子科技大学840物理光学考研真题答案.pdf`（75 页）

两份都是**纯扫描件**（`pdftotext` 取出来是空的），只能渲染成图逐题看：

```sh
pdftoppm -r 300 -gray -png -f 20 -l 21 <pdf> <前缀>
```

**读公式和数字必须 300dpi** —— 150dpi 下答案册的 `D` 会被看成 `B`。

每页都有 `【微信公众号：余哥成电考研】` 的行内水印（会把词劈成两半）和斜向大字水印，
转录时要还原被劈开的词、删掉水印，并去掉页眉页脚和「余哥团队学长解析:」这类署名。
`sa-build.py` 的校验会拦住漏删的水印。

## JSON 格式

```json
{
  "year": 2013,
  "kind": "exam",
  "source_pages_q": [31],
  "source_pages_a": [20, 21],
  "note": "简答题 6 题，每题 5 分，共 30 分。",
  "items": [
    {
      "num": 1,
      "q": "光从光密介质入射到光疏介质时，出现透射系数大于 1，这是否与能量守恒定律相矛盾？如何解释？",
      "a": [
        { "t": "p", "v": "不矛盾。……" },
        { "t": "list", "v": ["第一条", "第二条"] }
      ],
      "figs": ["2013-1.png"],
      "note": "",
      "src_note": ""
    }
  ]
}
```

- `kind`：`exam` = 卷面上的独立简答题大题；`collection` = 资料整理的常见题汇总
  （只有 2017 年），主页卡片上会标出来。
- `num`：**卷面题号**。答案册编号与卷面不一致时以卷面为准，并保证 `q` 与 `a` 是同一道题。
- `q`：题干，可含 HTML。要换行用 `<br>`，**不要用 `\n`**。
- `a`：答案块，只有 `p`（段落）和 `list`（分点）两种。公式写法见下。
- `figs`：题面带图时，把图裁到 `assets/sa/` 下，这里写文件名。原卷分值标注不要抄。
- `note`：**会渲染到题目上方**，只写学生看了有用的话 —— 题面本身在卷上就带的标注、
  「原书此处糊了」「答案册这道没给答案」这类。
- `src_note`：**不进 `sa-data.js`**，只给维护者看。原书的错字订正记在这里
  （学生手上没有原书，看到「原书作 X，已订正」只会一愣）。按惯例订正的错字：
  `及时`→`即使`、`吸收写书`→`吸收系数`、`干涉隐私`→`干涉因子`、`肥皂饱`→`肥皂泡`、
  `瑞丽散射`→`瑞利散射`、`行射`→`衍射`，以及 2016 年那道片堆题多出来的「你」字、
  「振动法方向」→「振动方向」。**读不出原意的不要猜**（2013「光长」、2014「球面波」、
  2015「节日」、2019「雾镜」、2020「虚波失」、2022「布瑞斯特/光由」都照原样留着，
  在 `note` 里说明）。

## 公式写法

站点已有的 CSS 类，答案和题干都用这一套：

| 用途 | 写法 |
|---|---|
| 斜体变量 | `<span class="m">E</span>` |
| 分式 | `<span class="frac"><span class="n">分子</span><span class="d">分母</span></span>` |
| 根号上划线 | `√<span class="rad">1 + x²</span>` |
| 下标 / 上标 | `<sub>0</sub>` / `<sup>2</sup>` |
| 希腊字母、运算符 | 直接写：λ π θ Δ φ ω ε μ ≤ ≥ ≠ ≈ × · ± ° |

不要求排版好看，要求跟原书一致、不丢信息。读不出来的公式在 `note` 里说明，**不要猜**。
