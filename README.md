# 李承霖大王的光学复习

手机优先的刷题网页，内容来自《物理光学》的简答题文档、课后答案，以及电子科技大学
840 物理光学考研真题。

分三个板块，主页顶部切换：

| 板块 | 题量 | 形式 | 作答方式 |
|---|---|---|---|
| **简答题** | 29 道 | 正文逐字录入，公式用 HTML 重排 | 点「显示答案」 |
| **选择题** | 258 道 | 2008~2024 真题逐题转录 | **点选项即作答** |
| **课后题** | 116 道 | 原稿逐题切图（含公式原样） | 点「显示答案」 |

## 功能

- **主页**：切换板块，选章节（第 4~8 章）/ 年份（2008~2023）或「全部」，显示刷题进度
- **刷题**：随机抽题 → 点「显示答案」→ 可标「还不熟 / 已掌握」→「下一题」
- **选择题**：点一个选项就算作答，当场判对错、圈出正确选项；答对自动标「已掌握」，
  答错自动标「还不熟」，也可以再手动改
- **选择题解析**：选完选项之后（不是之前）在下方展开这道题的解析，写清为什么这么选；
  收藏页里的选择题也带着解析显示
- **抽题规则**：优先抽没刷过的；全部刷完后优先复习「还不熟」的
- **收藏**：刷题时点右上角 ★ 收藏，收藏页可展开答案、取消收藏
- **图片放大**：点图 → 1x / 2x / 3x 循环，放大后拖动看细节，点空白处关闭
- **手写笔记**：每章的扫描手写答题笔记，可翻看，点图放大
- **进度记录**：存在浏览器 localStorage，关掉网页也不丢
- **离线可用**：首次打开后加入主屏幕，之后没网也能刷

## 内容来源与处理说明

### 简答题（`data.js`）

原 PDF 每个文件由两部分拼成：

| 部分 | 处理方式 |
|---|---|
| 后 2~3 页：印刷体简答题（题目 + 答案） | 逐字校录入 `data.js`，共 **29 道** |
| 前 2~6 页：扫描手写答题笔记 | 原图放进 `assets/notes/`，共 **19 页** |

录入时做的处理：

- 修正原文错别字：`人射`→`入射`、`行射`→`衍射`、`相相反`→`相反`、`比度降`→`对比度`
- 公式重新排版为可缩放的 HTML（麦克斯韦方程组、布儒斯特角推导、光栅分辨本领等），
  原文截图作为「教材原式」附在答案末尾，可点开放大
- 第 7 章第 6 题的「光隔离器结构示意图」原图被红色水印遮挡，已按原图重绘为 SVG
- 第 8 章第 2 题原文带「（2 分）」等评分标注，已去掉

### 选择题（`mc-data.js`）

源文件是 `840真题.pdf` 和 `电子科技大学840物理光学考研真题答案.pdf`，两份都是**纯扫描件、
没有文字层**（`pdftotext` 取出来是空的），所以只能靠看图逐题转录：

```
pdftoppm -r 400 -gray -png  →  逐题抄题干与选项、按答案册核答案
```

- 题面按年份分组（`y`），年份内按 `num` 排序
- 答案为 `a`：正确选项的下标，`0` 是 A；`null` 表示答案册没给字母
- 题干与选项都是**真文字**（不是切图），这是「能点选项作答」的前提；
  公式沿用简答题那套 HTML class（`.m` / `.frac` / `.rad`），填空的横线写成
  `<span class="blank"></span>`
- 少数题目卷面自带插图，切出来放在 `assets/mc/`，文件名写进 `fig` 数组

**答案的校验是两条独立路径**：转录 agent 看真题卷，我另外把答案册的答案行渲染成
400dpi 的图逐字读，两边对不上就查。这一步不是走过场 ——

- 曾在 150dpi 下把答案册的 `D` 读成 `B`，连错 2008、2009 两年；
  400dpi 复核后才发现。**读字母必须 400dpi。**
- 2012 年那个 agent 没照抄答案册、自己算了答案，10 道题跟答案册不一致；
  用物理逐个验算（等倾干涉同级环、牛顿环抬镜、F-P 腔、望远镜分辨极限、折射率椭球）
  确认**答案册是对的**，已按答案册改回。
- 全 12 年的答案行后来又在 400dpi 下逐字重读了一遍，只揪出 **1 处错**：
  2013 年第 9 题（薄膜插入后光程差变化）答案册是 **D**、题库原先记的是 B，已改正。
  这题的物理也站在 D 这边：插入膜后光程差的改变量是 2(n−1)t，
  令它等于 λ 得 t = λ/[2(n−1)]，而不是 λ/(2n)。

**收录结果：258 道题，12 个年份，257 道有答案。**

| 年份 | 题数 | 说明 |
|---|---|---|
| 2008 / 2009 | 20 / 20 | |
| 2010 | 21 | |
| 2011 | 20 | 第 8 题答案册记作「A、D 两说」，不计对错 |
| 2012 | 24 | 原卷 25 题，第 25 题是填空题、无选项，未收录 |
| 2013~2016 | 25 / 25 / 20 / 25 | |
| 2017 | 33 | 回忆版；卷面按章编排、每章题号各自从 1 开始，这里拉通编号 |
| 2022 | 8 | 回忆版；原卷 9 题，第 7 题无选项，未收录 |
| 2023 | 17 | 回忆版；原卷标「2 分 × 21」，但题号跳过 13，第 12/18/15 题缺选项，未收录 |

**没有选择题的年份**，不是漏了：

- **2018**：整卷没有选择题，从「一、简答题」直接开始
- **2021**：同上，卷面第一题就是「一、简答题」
- **2024**：`840真题.pdf` 里 2024 年只有一页声明（「真题及答案正在编写和校正中」），
  没有试题正文，答案册也没有
- **2019**（5 题）和 **2020**（1 题）：卷面本身不可作答 —— 2019 的 5 题全都只有文字叙述、
  一个选项都没印；2020 的唯一一题是「选出正确陈述的组合」，答案册记作 ③④，不是四选一

### 选择题解析（`mc-exp.js`）

**解析不是答案册里的东西。** 答案册（`电子科技大学840物理光学考研真题答案.pdf`）的
选择题部分只印了答案字母（形如「1-5 BCADC 6-10 BBBDD」），一个字的推导都没有，
后面的详细解答只覆盖计算题和简答题。所以 258 条解析全部是照题面自己推的。

单独放在 `mc-exp.js` 里、不塞进 `mc-data.js`，是为了让那份**生成的文件保持原样**
（`build.py` 重新跑一遍不会把解析冲掉）；`index.html` 在 `mc-data.js` 之后加载它。

```js
var MC_EXP = {
  "m2008-2": "临界角 45° 给出 n = 1/sin45° = √2 ≈ 1.414。…",
};
```

- 键是 `mc-data.js` 里的题目 `id`（`m{年份}-{题号}`），值是解析的 HTML 片段
- 解析里只用 `<i>`（变量）、`<b>`（关键结论）、`<sub>` / `<sup>`（上下标），
  **不带 HTML 属性** —— 这样 JS 字符串用双引号包着也不用转义
- 长度 30~350 字，按题目难度写：概念题一句话点破，计算题给出算式和中间量
- 答案册本身存疑的题（题干带「（题目存疑）」，如 2023 年第 4 题、2014 第 21 题），
  解析按答案册给的字母讲，同时把疑点写明白
- 显示时机：选择题的解析块放在「答题后」那一块里，选完选项才出现；
  没选之前页面上没有它。收藏页的选择题则直接带着解析显示

### 课后题（`hw-data.js`）

源文件是 `物理光学-课后答案-叶玉堂（52页）（已排版）.doc`。这份文档的题目和答案**全部以
MathType/OLE 公式对象排版**，文字层取出来是私用区乱码（`!`、`"#=!`、`$%&'` 这种），
复制粘贴、转 Markdown 都会丢公式，所以改成**逐题切图**：

```
.doc --Word/AppleScript--> PDF --pdftoppm 300dpi--> 每页 PNG
    --按题切--> assets/hw/{ch}-{num}-{q|a}[-n].png
```

切图的难点在于：公式的 y 坐标在文字层里常常排在同一视觉行的中文之前或之后，
按文字行的文档顺序切会把公式算进上一题。所以 `crop.py` 的做法是

1. 只把**含汉字或全角标点的行**当作分段的锚（公式乱码行不参与定界）；
2. 把页面按**墨迹带**（连续的有墨迹的像素行）切开，带内间隙小于 4pt 的合并
   —— 一个高分式的分子/分母/横线本来就只隔一两个像素，必须当成一行；
3. 网页中间的整带公式（推导过程）按「归属它上面那条锚行」跟随，这样纯公式的
   整段推导不会丢。

`verify.py` 是独立校验，不信 `crop.py` 的任何区间，只拿可读文字行反查成品图：
漏字（可读行不在本题任何图里）、串题（本题图里出现别题的行）、切字（图边界落在
行框中间）、顶边过高（疑似混入上一题的公式尾巴，专抓纯公式错位）。

当前结果：**275 张图，13.2 MB，116 道题题面答案齐全，四项校验全部通过**
（仅 1 处 0.6pt 的切字，落在留白里，无影响）。

题目与答案分开存，题面在 `q`、答案在 `a`，页面上题面直接显示、答案点了才出。
切图是白底位图，样式里强制 `background:#fff`，深色模式下也是白底黑字。

> 提醒：课后答案是**红果研考研教育的付费资料**，两份真题 PDF 也带着
> 「余哥成电考研」的水印、是付费考研资料。仓库若为公开（GitHub Pages
> 免费版只能用公开仓库），这些内容即可被搜索引擎检索到。

## 修改题库

简答题都在 `data.js` 里，格式：

```js
{
  id: "c4q1",        // 唯一 ID，改了会丢失该题的刷题记录
  ch: 4,             // 章节号
  num: 1,            // 题号（显示用）
  q: "题目文字",
  a: [               // 答案块，按顺序显示
    { t: "p",    v: "一个段落" },
    { t: "list", v: ["条目一", "条目二"] },
    { t: "note", v: "灰色旁注" },
    { t: "img",  v: "assets/figs/xxx.png", cap: "图注" },
    { t: "svg",  v: "<svg>…</svg>",       cap: "图注" },
  ],
}
```

答案里可直接写 HTML，公式用现成的 class：

- 斜体变量：`<span class="m">E</span>`
- 分式：`<span class="frac"><span class="n">分子</span><span class="d">分母</span></span>`
- 根号上划线：`√<span class="rad">1 + x²</span>`

课后题在 `hw-data.js` 里，格式：

```js
{
  id: "h4-2",       // 唯一 ID（h + 章号 - 题号）
  ch: 4,            // 章节号
  num: 2,           // 题号（显示用）
  t: "一列平面光波从A点传到B点，…",   // 题面摘要，列表和分享用
  q: ["4-2-q.png"],                    // 题面切图，按顺序显示
  a: ["4-2-a-1.png", "4-2-a-2.png"],   // 答案切图，跨页的按 -1 -2 排
}
```

图片放在 `assets/hw/` 下，文件名即数组里的值（不带路径）。

选择题在 `mc-data.js` 里，格式：

```js
var MC_YEARS = [ { id: 2008, title: "真题选择题", sub: "840 物理光学", n: 20, note: "…" } ];
var MC = [
  {
    id: "m2008-1",   // 唯一 ID（m + 年份 - 题号）
    y: 2008,         // 年份，同时也是分组用的 ch 参数
    num: 1,          // 卷面题号
    q: "题干文字，可用 HTML",
    o: ["选项 A", "选项 B", "选项 C", "选项 D"],
    a: 3,            // 正确选项下标（0 = A）；null = 答案册没给
    note: "灰色旁注，可省略",
    fig: ["2008-14.png"],   // 插图，可省略；文件放 assets/mc/ 下
  },
];
```

`mc-data.js` 是从 `/tmp/po_extract/mc/build.py` 生成的，不要手改 —— 要改就把那批
`out/*.json` 改了重新生成。

改完 `data.js` / `mc-data.js` / `mc-exp.js` / `hw-data.js` / 任何图片后，把 `sw.js` 里的
`CACHE` 版本号 +1（当前 `po-quiz-v5`），否则手机上可能一直用旧缓存。
**换图必须 +1** —— 图片名不变时缓存优先策略不会去取新的。
